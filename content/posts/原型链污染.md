## `prototype`与`__proto__`

### `prototype` 显式原型

JavaScript中有一个特殊的地方就是<u>函数也是对象</u>,对象可以放属性,而函数一样可以放属性,`prototype`就是函数的一个属性

例子:

```javascript
function Person(){}
console.log(Person.prototype);

//当创建一个函数的时候,会自动创建 Person.prototype,就像Person.name等属性一样
prototpye的内容是
{
    constructor: Person
}
结果是{}, 因为默认不可枚举
```

### new 的实际过程

````javascript
function Person(){}
let p = new Person();

1. 创建对象：
let p = {};
2. 连接原型：
p.__proto__ = Person.prototype;
3. 执行函数：
Person.call(p);
4. 返回
return p;
````

### `__proto__` 隐式原型

`proto`是所有对象的属性(包括函数、数组、普通对象)

它是对象内部的一个指针，指向创建该对象的构造函数的 `prototype`例如:

```javascript
let obj = {};
javascript自动执行obj.__proto__,里面是Object.prototype

```

## 什么是原型链

```javascript
function Person(name) {
    this.name = name;
}

Person.prototype.age = 18;
Person.prototype.sayHi = function () {
    console.log("你好");
};

let jack = new Person("Jack");
```

当访问对象的属性的时候,JavaScript的查找顺序是:

1. 先在对象的自身属性里面找
2. 找不到,再去`Jack.__proto__`(即`Person.prototype`)中找
3. 再找不到,去`Person.prototype.__proto__`(即`Object.prototype`)中去找

一直找到`Person.prototype.__proto__`也就是Null ,还找不到就返回undefined

## 漏洞产生的原因:

因为所有的JavaScript对象都指向`Object.prototype`,所以只要能修改`Object.prototype`增加一个属性,那么所有的对象都会拥有这个属性

一般漏洞出现在对象合并,对象克隆,路径赋值中.例子:

```javascript
function merge(target, source) {
    for (let key in source) {
        if (key in target && key in source) {
            merge(target[key], source[key]); // 递归合并
        } else {
            target[key] = source[key];
        }
    }
}
```

传入:

```javascript
{
  "__proto__": {
    "isAdmin": true
  }
}

变体
{
    "constructor": {
        "prototype": {
            "isAdmin": true
        }
    }
}
```

那么所有的全局对象的isAdmin都会变成ture
